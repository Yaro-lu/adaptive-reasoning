# 官方上架教程 / Official submission walkthrough

日期 / Date: 2026-09-22

GitHub 仓库公开与 Codex 官方目录上架是两件事。这里说明后者；本材料没有代你提交审核。

A public GitHub repository and an official Codex directory listing are separate. This guide covers the latter; these materials do not constitute a submitted review.

## 第 1 步：准备发布者资料 / Step 1: Publisher details

准备真实发布者身份及公开的官网、支持、隐私政策、使用条款网址。官网可先考虑仓库主页，支持可考虑 Issues 页面，最终是否接受以门户审核为准。隐私与条款必须由你确认并公开；不要填写不存在的网址。

Prepare your real publisher identity and public website, support, privacy, and terms URLs. Consider the repository for the website and Issues for support, subject to portal review. Confirm and publish your own policies; do not enter nonexistent URLs.

仓库：https://github.com/Yaro-lu/adaptive-reasoning

支持候选：https://github.com/Yaro-lu/adaptive-reasoning/issues

本地兼容清单里的 `Unpublished local build` 仅供开发。若上传完整插件包，先让 Codex 把作者字段替换成你确认的发布者，并重新校验打包；不要把它作为公开身份提交。

`Unpublished local build` in the local compatibility manifest is a development marker. Before uploading a complete plugin package, have Codex replace it with your confirmed publisher information and revalidate/repack it.

## 第 2 步：打开入口 / Step 2: Open the portal

打开 [插件提交入口](https://platform.openai.com/plugins)，登录并选择正确组织。需要已验证发布者及 Apps Management 写入权限；没有入口时先检查组织权限。

Open the [submission portal](https://platform.openai.com/plugins), sign in, and select your organization. A verified publisher and Apps Management write access are required.

## 第 3 步：创建草稿 / Step 3: Create a draft

选择 **Create plugin → Skills only**。本插件没有 MCP 服务。

Choose **Create plugin → Skills only**. This plugin has no MCP server.

## 第 4 步：填写介绍 / Step 4: Listing

打开 [目录文案](目录文案.zh-en.md)，复制名称、描述、开场提示和发布说明到对应字段。选择实际 Developer Identity；按表单填写网址、类别、地区。图标可用同目录的 `logo.png`，它是本项目原创几何图案。

Copy the name, descriptions, starter prompts, and release notes from [Listing copy](目录文案.zh-en.md). Select your real Developer Identity and fill in URLs, category, and regions. Use the original geometric `logo.png` in this folder if desired.

## 第 5 步：上传技能 / Step 5: Upload skills

在 **Skills** 上传最终技能包。准备好的 `adaptive-reasoning-skill-0.1.0.zip` 仅含技能目录及引用文件；完整本地插件包另为 `adaptive-reasoning-0.1.0.zip`。不要上传包含本教程的整套材料包，也不要上传本机测试状态或会话日志。

In **Skills**, upload the final skill bundle. `adaptive-reasoning-skill-0.1.0.zip` contains only the skill directory and references; `adaptive-reasoning-0.1.0.zip` is the complete local plugin package. Do not upload the entire preparation kit or local session logs.

上传后检查能否识别 `adaptive-reasoning` 和 SKILL.md。本机未登录门户实测上传；如果页面要求不同压缩层级或格式，将报错文字交给 Codex，保留技能内容重新打包，不要绕过扫描。

Confirm that the portal recognizes `adaptive-reasoning` and SKILL.md. Portal upload has not been tested locally. If a different archive layout is required, give the error text to Codex for repackaging without changing instructions or bypassing scanning.

## 第 6 步：填写测试 / Step 6: Tests

把 [审核用例](审核用例.zh-en.md) 中 P1–P5、N1–N3 填入 Testing，保留环境要求和预期。它们是审核方案；不要把未执行项写成通过。此 Skill 依赖 Codex 任务接口，不承诺在普通 ChatGPT 对话中切换模型。

Enter P1–P5 and N1–N3 from [Reviewer tests](审核用例.zh-en.md) in Testing, preserving setup and expectations. These are review procedures, not eight passed tests. The skill requires Codex task interfaces; ordinary ChatGPT switching is not promised.

## 第 7 步：提交审核 / Step 7: Submit

核对全部信息，确认适用声明，点击 **Submit for Review**。此时进入审核，还未公开上架。

Review all fields, confirm applicable attestations, and select **Submit for Review**. This starts review, not public availability.

## 第 8 步：审核后发布 / Step 8: Publish after approval

如需修改，按反馈修正再提交；通过后在门户执行发布。审核没有保证时限。

Address review feedback if requested. After approval, publish from the portal. No review duration is guaranteed.

依据：[OpenAI 官方提交文档](https://developers.openai.com/plugins/deploy/submission)。页面字段可能变化，以当时门户为准。

Source: [OpenAI submission documentation](https://developers.openai.com/plugins/deploy/submission). Follow the current portal if fields change.
