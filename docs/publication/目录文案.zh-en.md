# 目录文案 / Listing copy

## 名称 / Name

自动推理强度 · Adaptive Reasoning

## 简短描述 / Short description

按开发任务难度调整推理强度，核验后继续同一任务。

Adapt reasoning effort to development difficulty and verify same-task continuation.

## 详细描述 / Long description

Adaptive Reasoning 是面向 Codex 开发任务的纯 Skill 插件。以用户当前模型和强度为基准，动态读取支持档位，在有依据的复杂问题中逐档提高强度，保存交接，并在下一轮核验实际配置后继续工作。

Adaptive Reasoning is a skills-only plugin for Codex development tasks. It starts from the user's current model and effort, discovers supported levels, escalates when complexity warrants it, and saves a handoff before verifying the actual configuration in the next turn.

0.2.0：以用户所选模型为基础，自动目标只使用 medium/high/xhigh，所有型号均跳过 low 及更低档位。需要 ultra 时先建议可用的 Astra 或 Sol 版本，等待用户为本次专项选择，再设置和接续；用户可选择保持当前档位。初始低档在同模型规范化，恢复不会回 low。

Version 0.2.0 uses the selected model with medium/high/xhigh automatic targets, excluding low and lower tiers across all models. Before ultra, it recommends available Astra/Sol variants and waits for the user's current-stage choice before preparing settings and continuing. Staying at the current effort is an option. A low start is normalized on the same model and never restored to low.

跨模型默认关闭，只有用户授权明确路线后才执行。包含冷却、单条待处理队列和用户手动选择优先规则。新模型出现不会自动替换当前模型。

Cross-model switching is disabled by default and requires an explicitly authorized route. Cooldowns, a single pending continuation, and user overrides guide the workflow. New catalog entries do not automatically replace the current model.

需要具备任务设置、同任务排队和实际轮次读取能力的 Codex 环境。本机 Windows 切换链路已验证；macOS/Linux、xhigh 和长期自动难度判断准确率尚未实测。不附带服务或遥测，不保证降低用量。

Requires Codex with task settings, same-task queuing, and actual turn metadata. The switching flow is verified locally on Windows; macOS/Linux, xhigh, and long-term difficulty assessment remain untested. No server or telemetry is bundled, and reduced usage is not guaranteed.

## 开场提示 / Starter prompts

1. 使用 $adaptive-reasoning 继续开发，按难度调整强度，保持当前模型。

   Use $adaptive-reasoning for development; adapt effort while keeping the current model.

2. 本任务启用 $adaptive-reasoning，自动升档上限为 high。

   Use $adaptive-reasoning for this task with an automatic effort ceiling of high.

3. 使用 $adaptive-reasoning 检查当前模型和实际档位，不执行切换。

   Use $adaptive-reasoning to inspect the current model and actual effort without switching.

提交版本 0.2.0，尚未有官方已发布版本。新增 medium 下限和每个 ultra 专项的模型建议、等待选择机制，保留实际档位核验。无 MCP、hooks 或打包执行程序。0.1.0 Windows 本机三阶段切换接续通过；0.2.0 新流程为规则走查，ultra 执行、用户选择接续、自主触发效果和跨平台兼容性需进一步验证。审核需要上述 Codex 任务接口；无独立服务账号。

Submission version 0.2.0; no version is officially published yet. Adds a medium floor and per-stage ultra recommendations with a blocking user choice, retaining actual-effort verification. No MCP, hooks, or executables are bundled. Three 0.1.0 Windows continuation stages passed. The 0.2.0 changes have document-based review; ultra execution, choice continuation, autonomous triggers and cross-platform behavior require further validation. Review requires the described Codex interfaces; no separate service account is needed.
